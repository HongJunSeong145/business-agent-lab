# 스테이징(테스트 사이트) 사용 가이드

테스트 사이트는 **직접 눌러 보며 확인하는 곳**입니다. 화면 맨 위 노란 띠 "테스트 환경 — 실제 데이터 입력 금지"가 보이면 테스트 사이트입니다.
**실제 학생 이름·연락처·학번은 넣지 마세요.** 들어 있는 사람·업체·전화번호는 모두 가상입니다.

## 1. 접속

- 주소: Render 대시보드 → `kgb-agent` 위쪽에 보이는 `https://kgb-agent-xxxx.onrender.com` (설치 방법은 `docs/DEPLOY.md`)
- 오래 안 쓰면 잠들어 있어 첫 접속에 30초~1분 걸릴 수 있습니다.

## 2. 테스트 계정

비밀번호는 이 저장소에 적지 않습니다. **Render 화면에서 직접 정한 값**을 씁니다.

| 계정 | 역할 | 비밀번호 |
|---|---|---|
| `INITIAL_ADMIN_EMAIL` 로 정한 이메일 | 관리자(회장과 같은 권한 + 백업) | `INITIAL_ADMIN_PASSWORD` |
| `president@demo.kgb.invalid` (김데모) | 학생회장 | `SEED_DEMO_PASSWORD` (정했을 때만) |
| `planning.head@demo.kgb.invalid` (이기획) | 기획국장 | 〃 |
| `planning.member@demo.kgb.invalid` (박기획) | 기획국원 | 〃 |
| `finance.member@demo.kgb.invalid` (정재정) | 재정국원 | 〃 |
| `secretariat.head@demo.kgb.invalid` (강사무) | 사무국장 | 〃 |
| `secretariat.member@demo.kgb.invalid` (조사무) | 사무국원 | 〃 |
| `promotion.member@demo.kgb.invalid` (장홍보) | 홍보국원 | 〃 |
| `operations.member@demo.kgb.invalid` (한집행) | 집행국원 | 〃 |

> 국장은 회장과 같은 권한입니다(부회장 없음). 국원은 자기 국서·자기 업무만 고칠 수 있습니다.
> 여러 역할을 동시에 보려면 브라우저 **시크릿 창**을 하나 더 열어 다른 계정으로 로그인하세요.

## 3. 시나리오 체크리스트

순서대로 해 보고, 이상한 점은 화면 캡처와 함께 알려 주세요. (괄호는 내부 테스트 번호)

### A. 기본 화면 (관리자)
- [ ] 대시보드: 배너 → 최근 회의록 → 분기 캘린더 → 30일 일정 → 사업 진척도 → 국서 카드 5개 → 인적사항 → 연락망 순서 (T26)
- [ ] 배너 편집에서 부제·사진 바꾸기
- [ ] 위쪽 검색창에 "간식" → 결과를 눌러 이동
- [ ] 종 모양 알림 열기 → 모두 읽음

### B. 회의록 → AI 제안 → 승인 (AI 키를 넣었을 때)
- [ ] 회의록 → `[데모] 제12차 정기회의` → **AI 분석** → 정리본에서 "원문 ¶" 링크를 눌러 원문 위치로 이동 (T2)
- [ ] 위쪽 **검토 대기** → 업무 제안 확인, 날짜 하나 고쳐서 **선택 승인** (T3)
- [ ] 회의록 업로드(HWPX·DOCX·PDF·TXT) → "추출 완료" (T1)
- [ ] AI 키가 없을 때: "AI 일시 사용 불가"가 보이고, 업무는 직접 만들 수 있음 (T25)

### C. 사업·일정
- [ ] 사업 → `[데모] 연말 단과대 축제`(교비·외부업체): 행정실 송부일·업체 확정일, 세금 포함 총액 (T5·T9)
- [ ] 행사일을 바꿔 보기 → 제안 마감만 다시 계산되는지 (T16)
- [ ] 분기 캘린더에서 업무 마감을 끌어다 옮기기 → 확인 창 → 확정

### D. 기획안·레퍼런스 (홍보국원·기획국원)
- [ ] 기획국원(박기획): 사업 › 기획안 양식 채우기 → 새 버전 저장 → 결재 요청
- [ ] 관리자: 기획안 **결재** → 홍보물·집행 매뉴얼 업무가 "차단"에서 풀림 (D7)
- [ ] 홍보국원(장홍보): 업무 › 레퍼런스 › **레퍼런스 제작 의뢰**(지시 입력) → 1~3분 뒤 출처 링크·예시안·포스터 목업 (T19, AI 필요)

### E. 작업물·진척도 (홍보국원)
- [ ] 업무 › 작업물에 이미지 올리기 → AI 평가 점수·부족 항목 (T12·T13, AI 필요)
- [ ] 같은 작업물에 2차 버전 올리기 → 점수 갱신
- [ ] 진척도 막대 눌러 40% → 새로고침해도 40% (T14)
- [ ] 완료 체크 → 100% → 실행 취소 → 원래 값 (T15)

### F. 재정·모니터링 (재정국원)
- [ ] 재정 → 4분기 → 교비 라인 1,000,000원 추가 → 세금 100,000·총액 1,100,000 → CSV 내보내기 (T9)
- [ ] 사업 › 재정: 구입 항목 추가 → "구입 완료" → 영수증 경고 → 영수증 올리기 → 경고 사라짐 → 검수 (T20)
- [ ] 관리자: 재정 → **지금 점검** → 알림 생성 확인

### G. 권한·명부 (국원)
- [ ] 홍보국원: 인적사항에서 남의 칸은 고칠 수 없음, 내 칸은 고쳐짐 (T21)
- [ ] 관리자: 연락망에 열 추가·이름 바꾸기·삭제·되돌리기 → 새로고침 후 유지 (T22)
- [ ] 국원: 회의록 업로드 버튼 없음, 다른 국서 업무 완료 체크 불가 (T23)

## 4. 데이터 초기화

테스트 데이터가 엉망이 되면 처음 상태로 되돌릴 수 있습니다(운영에서는 실행되지 않음).
Render → `kgb-agent` → **Shell** 에서:

```bash
npm run staging:reset -- --yes && npm run db:seed
```

그다음 **Manual Deploy → Restart** 하면 관리자·데모 데이터가 다시 들어갑니다(데모 사업·회의록은 `SEED_DEMO=true` 일 때 처음 한 번).
