## Phase 1 — 기반 구축

**일자**: 2026-10-31 · **브랜치**: `claude/great-cray-kgz7nw`

### 구현한 기능
- pnpm 워크스페이스: Next.js 16(App Router) 앱 + `@kgb/rules`(규칙 엔진 패키지, 이번 Phase는 진척도·분기 함수)

- 인증(Auth.js v5): 이메일+비밀번호 로그인, 초대 링크 가입(72시간·1회용·재초대 시 이전 링크 무효), 로그아웃, 비밀번호 변경 시 전체 세션 무효화, 5회/15분 로그인 제한, argon2id

### 구현 중 바뀐 점·발견한 문제
- `effective_progress`: 생성 컬럼 → 뷰로 변경(Prisma 드리프트 문제, ADR-007 갱신).
- React 19 폼 액션이 오류 후 입력값을 지우는 문제 → 오류 시 입력값 유지하도록 수정.
- 빌드 단계에 DB 주소가 없으면 빌드가 실패하던 문제 → Prisma 클라이언트 지연 생성으로 수정(새 클론 재현으로 발견).
- Render 실제 배포는 사용자 계정이 필요해 이 환경에서 직접 확인하지 못함. 같은 명령으로 로컬 재현까지 확인함.
- Docker 데몬이 없는 환경이라 `docker-compose.yml`은 실행 검증하지 못함(표준 postgres:16 구성).

## Phase 2 — 회의록 업로드·추출·회의록 공간 (AI 없이)

**일자**: 2026-10-31 · **브랜치**: `claude/great-cray-kgz7nw` · 참고 자료: 사용자 제공 실제 회의록 PDF 1건(저장소에 넣지 않음)

### 구현한 기능
- 업로드: 상단 바·회의록 페이지의 "회의록 업로드" 대화상자 — 파일 선택/끌어 놓기 또는 텍스트 붙여넣기, 회의일·유형·제목. 국장 이상(설정 `MEMBER_CAN_UPLOAD_MINUTES`로 국원 허용 가능, Q4)
- 형식 검사: 확장자 허용 목록 + 매직바이트 일치, 용량 상한(설정값, 기본 50MB), 실행 파일 등 거부
- 파일 저장 추상화: `local`(개발) / `db`(Postgres, 배포 기본) — 무작위 저장 키, 원래 파일명은 키에 미포함
- 서명 URL 다운로드(10분 만료) + 로그인 + 소유 기수 확인, `nosniff`·sandbox CSP
- 작업 큐: pg-boss + `ai_jobs`, 웹 서버 내장 워커(inline), 별도 워커(`npm run worker`) 선택 가능, 멈춘 작업 자동 복구
- 형식별 추출(ADR-022): PDF(2-up 소책자 인식·자간 이름 결합·쪽 번호 제거), DOCX, HWPX(표 → "칸 | 칸"), HWP(최선 노력, 미리보기 대체), TXT/MD(UTF-8·EUC-KR)
- 상태 흐름: uploaded → extracting → extracted / failed(안내 문구), 화면 자동 갱신(2초 폴링), "다시 추출"·"파일 다시 올리기"
- 회의록 페이지(`/minutes`): 목록(제목 검색·기간·유형 필터) + 상세 탭 [정리본(Phase 5 안내) / 원문(문단 번호 — Phase 5 원문 위치 연결의 기준) / AI 제안(Phase 5 안내) / 파일(원본 내려받기·추출 방식·SHA-256)]
- 대시보드: 최근 회의록 → 드로어(상태·원문 미리보기·회의록 공간 링크), "전체 회의록 보기"
