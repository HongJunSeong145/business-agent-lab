## Phase 1 — 기반 구축

**일자**: 2026-10-31 · **브랜치**: `claude/great-cray-kgz7nw`

### 구현한 기능
- pnpm 워크스페이스: Next.js 16(App Router) 앱 + `@kgb/rules`(규칙 엔진 패키지, 이번 Phase는 진척도·분기 함수)
- Prisma 7 스키마 전체(PART 4, 42개 테이블) + 1차 마이그레이션: CHECK 제약, 부분 고유 인덱스(업무당 lead 1개, pending 제안 dedupe, 현재 기수 1개), `task_progress` 뷰, 되돌리기 `down.sql`
- 인증(Auth.js v5): 이메일+비밀번호 로그인, 초대 링크 가입(72시간·1회용·재초대 시 이전 링크 무효), 로그아웃, 비밀번호 변경 시 전체 세션 무효화, 5회/15분 로그인 제한, argon2id
- 권한 함수 `lib/auth/can.ts` (국장 = 회장, 부회장 없음, 백업은 관리자 전용)
- 디자인 토큰(`lib/design/tokens.ts` ↔ `app/globals.css`), Pretendard 글꼴, 진척도 막대(채움 끝 경계선)·국서 칩
- 공통 레이아웃: 상단 바(검토 대기 수·알림 수는 DB 실데이터), 사용자 메뉴, URL 쿼리(`?task=` 등) 사이드 드로어 셸
- 메인 대시보드 셸: 지시서 8-2 순서 고정, 모든 값 DB 실데이터(분기 탭은 기수 설정값 기준, 국서 카드 5개 순서 고정, 인적사항·연락망 표시)
- 설정: 회원·초대 관리, 내 계정(비밀번호 변경)
- 시드(재실행 가능): 기본 구조(학생회·기수·국서 5·설정 파라미터·연락망 기본 열 8·예결산 분기 4) + 초기 관리자 + 데모 데이터(`is_demo`, 화면에 "데모 데이터" 표시, 가상 인물만)

### 구현 중 바뀐 점·발견한 문제
- `effective_progress`: 생성 컬럼 → 뷰로 변경(Prisma 드리프트 문제, ADR-007 갱신).
- React 19 폼 액션이 오류 후 입력값을 지우는 문제 → 오류 시 입력값 유지하도록 수정.
- 빌드 단계에 DB 주소가 없으면 빌드가 실패하던 문제 → Prisma 클라이언트 지연 생성으로 수정(새 클론 재현으로 발견).
- Render 실제 배포는 사용자 계정이 필요해 이 환경에서 직접 확인하지 못함. 같은 명령으로 로컬 재현까지 확인함.
- Docker 데몬이 없는 환경이라 `docker-compose.yml`은 실행 검증하지 못함(표준 postgres:16 구성).
